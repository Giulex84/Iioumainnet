Privacy Policy

Last updated: 22 September 2026

IIOU is a personal IOU record-keeping application for Pi Network users. We collect only the data needed to provide shared IOU records, authenticate users, process the optional app-support payment, and protect account access.

Data we process

When you sign in with Pi, we process your Pi user ID and username. For IOUs, we store participant usernames, internal Pi user IDs when available, amounts, notes, due dates, status changes, settlement timestamps, recurrence settings, suggested installment plans, reminders, shared activity notes and partial-settlement records.

Authentication

IIOU uses Pi SDK authentication only. The server verifies Pi access tokens with the Pi Platform API. We do not provide password, email, social-login or fiat-payment authentication.

Storage and access

Product records are stored in persistent backend storage and are namespaced for the IIOU Mainnet application. Access to an IOU is limited to its participants as verified server-side.

Payments and custody

The core IIOU ledger is non-custodial. IIOU does not hold, lend, escrow or route Pi between IOU participants. A settlement record in IIOU is a shared application record between users and is not, by itself, proof of a blockchain transfer.

IIOU may offer an optional Pi Mainnet support payment to the application. When you initiate it, Pi Network processes the transaction and IIOU's server validates payment identifiers and transaction status needed to approve and complete the payment. This support payment does not modify, settle or validate any personal IOU.

Aggregate telemetry

We count daily pseudonymous users and aggregate events such as sign-ins, IOU creation, lifecycle actions, settlements and completed support payments. Pi user identifiers are transformed with a server-side keyed hash before counting. Telemetry does not contain IOU notes, counterparties or amounts and is visible only to the application administrator.

Retention

IOU records may remain available so participants can retain a settlement history. Closed IOUs can be archived in the interface. We may retain limited technical and payment-processing records for security, reliability, fraud prevention and reconciliation.

Sharing

We do not sell personal data. Data is shared only with service providers required to operate the app, such as hosting, storage and Pi Network platform infrastructure, or when legally required.

Contact

For privacy questions, use the contact information published in the Pi Developer Portal listing for IIOU.
